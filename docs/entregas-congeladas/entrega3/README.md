# Documento completo de la Entrega 3

[`informe_entrega3_completo.tex`](informe_entrega3_completo.tex) es el documento autocontenido
que se entregó para la Entrega 3, antes de que el manuscrito pasara a ser un único documento
acumulado (`docs/latex/main.tex`, veinte `\input` que reúnen E1-E4). Vivía suelto dentro de
`docs/latex/`, sin que ningún documento lo incluyera —una revisión externa lo señaló como
confuso: parecía parte del documento vivo, pero no se compilaba con él— así que se traslada aquí
junto a las demás instantáneas de entregas anteriores (Entregable 26 de la guía de cierre:
"Separación entre documento vivo y documento congelado"), en vez de dejarlo suelto o borrarlo.

No se recompila ni se actualiza: es el registro de qué se entregó en ese momento. El contenido
equivalente y vigente vive integrado en `docs/latex/main.tex` (Parte "Fundamento heredado",
Secciones de Entregas 1-3).
